# 데모 시나리오 — **3분**

> 2026-08-09 · 윤현석. 심사/발표용 **시간표**다.
> 기다릴 수 없는 구간(파싱·문항 생성·진단 조달)은 **전부 사전 준비**다.
> 긴 설명·여유 장면은 끝에 부록으로만 둔다.

---

## 0. 3분에 담는 말 — 하나만

> **"PDF를 올리면, 아는 건 줄이고 모르는 건 앞에 채운 수업이 되고,
> 그 안에서 읽고·꺼내고·다시 꺼낸 기록이 하나의 준비도로 모입니다."**

장면을 넷만 쓴다. 넷을 넘기면 3분이 깨진다.

| # | 장면 | 초 | 보여줄 것 |
|---|---|---|---|
| 1 | 목차가 바뀐다 | 0:00–0:50 | 진단 → 보강 단원(✚) |
| 2 | 읽고 바로 꺼낸다 | 0:50–1:40 | 설명 · 교재 원문 · 빈칸 |
| 3 | 네 출처가 한 숫자 | 1:40–2:20 | `/analysis` |
| 4 | 근거가 있는 문제 | 2:20–3:00 | `/quiz` 1문항 + 교재 쪽수 |

업로드 실연은 **넣지 않는다.** 3분 안에 파싱이 안 끝나고, 넣으면 ①이 죽는다.
(여유 있을 때만 부록 A.)

## 1. 발표 전날·직전에 할 일

```bash
docker compose up -d --build
docker compose exec backend uv run alembic upgrade head

# 시연용 수업이 있는지
docker compose exec backend uv run python scripts/demo_seed.py --list

# 누적 채우기 — 분석 막대가 비면 ③이 죽는다
docker compose exec backend uv run python scripts/demo_seed.py --doc <수업id> --sections 20

# 문제은행 (실측 888초 ≈ 15분) — 발표 한참 전에
curl -X POST "http://localhost:8000/api/courses/<수업id>/quiz/from-parsing/<문서id>" \
     -H "X-User-Id: 00000000-0000-0000-0000-000000000001"

# 화면 prewarm — 자료 개요를 한 번 열면 자동
```

### 체크리스트 (발표 5분 전, 눈으로)

```
[ ] 로그인 안 함 (dev 유저). 구글 로그인하면 책장이 비어 보인다
[ ] /library          시연용 수업 카드 1장
[ ] /curriculum/<id>  목차에 ✚ 보강 단원이 보이고, 교재 단원이 바로 아래
[ ] 보강이 10개면     실패. 교재가 안 보인다 → §4. 다른 수업으로 바꾸거나 진단 재설정
[ ] 화면 하나 클릭    즉시 열림 (prewarm). cold 5초면 리허설 실패
[ ] /analysis         출처 막대 셋 이상
[ ] /quiz             과목 카드에 문항 수 > 0
[ ] 브라우저           localhost:5173 · 북마크 네 개(책장·수업·분석·문제집)
```

## 2. 3분 대본 (초 단위)

### ① 0:00–0:50 · 진단이 **목차**를 바꾼다

```
/library → 시연 수업 → (이미 진단 끝난 상태) 학습 화면 목차
```

말할 것 (약 40초):

> "시험을 보는 진단이 아닙니다. **설정을 고릅니다.**
> 모른다고 한 과목은 교재에 없어도 목차 **앞에** 단원으로 넣습니다.
> 점수가 아니라 **다음에 배울 순서**가 바뀝니다."

손가락으로:

1. 사이드바에서 ✚ / "먼저 채우기" 보강 단원 하나
2. 바로 아래 교재 단원(원래 책)

숫자 (있으면 말함, 없으면 생략):

```
진단 전  목차 4  · 화면 ~47
진단 후  목차 14 · 화면 ~60   ← 앞에 보강
```

⚠️ **진단 화면을 그 자리에서 돌리지 않는다.** ③ 카드·⑥ 조달이 초를 먹는다.
   리허설에서 진단까지 끝낸 수업을 연다.

---

### ② 0:50–1:40 · 읽고 **바로 꺼낸다** (50초)

```
보강이 아닌 교재 단원 → 화면 하나
```

순서 그대로:

1. 설명 스크롤 (한 호흡)
2. **📎 교재 원문** 펼침 — "요약이 아니라 이 책 문장입니다"
3. **꺼내보기** 빈칸 하나 — 맞추거나 일부러 틀려도 됨

> "읽기만 하면 안 남습니다. 읽고 바로 꺼내게 합니다.
> 틀리면 그 개념이 다음 설명에 다시 나옵니다."

그림이 있으면 한 장만 스치듯. 설명하지 않는다.

---

### ③ 1:40–2:20 · 네 출처가 **한 준비도** (40초)

```
헤더 → 분석 (/analysis)
```

> "여기가 다른 점입니다. 진단·인출·복습·형성평가가 **무게를 달리 해서**
> 하나의 준비도로 모입니다. 이해도·진도·회상 중 하나라도 0이면 준비된 게 아닙니다."

손가락으로:

1. 출처별 막대 (×0.5 ~ ×2.0)
2. "자주 걸리는 개념" 한 줄

⚠️ 막대가 하나(`retrieval`만)면 이 장면은 뺀다. 시드 없이 열지 말 것.

---

### ④ 2:20–3:00 · 근거가 있는 문제 (40초)

```
/quiz → 시연 과목 → 범위 최소 → 1문항 → 제출
```

> "학습 기록과 **섞이지 않는** 문제은행입니다.
> 채점하면 정답만이 아니라 **교재 몇 쪽**이 같이 나옵니다."

손가락으로 **근거 원문/쪽수**만 찍고 끝.

시계가 3:00을 넘기면 채점 전에 끊고 쪽수만 보여도 된다.

## 4. 위험과 대비

| 증상 | 대비 |
| --- | --- |
| 보강 단원 과다(교재가 안 보임) | 다른 시연 수업으로 교체. ①에서 교재 단원이 보이는지 필수 확인 |
| 화면 cold 5초 | prewarm 안 됨. 발표 전 개요·화면 한 번 열기 |
| `/analysis` 막대 1개 | `demo_seed.py` 재실행. ③ 스킵하고 ②를 늘림 |
| `/quiz` 문항 0 | 15분 생성을 안 건 것. ④ 스킵, ③으로 끝 |
| 실수로 구글 로그인 | 책장 빔. 시크릿/로그아웃 없이 새로고침 전 로그아웃 |
| LLM 지연 | 새 화면·진단 ③을 그 자리에서 열지 말 것 |

## 5. 말하지 말 것 (3분용)

- 파싱 파이프라인 단계 수, alembic, 브랜치 이름
- "러닝 스타일 맞춤" — ③ 카드는 **읽기 편한 형식**이지 효과 주장이 아님
- 문제은행 저장률·폐기 수 — 물을 때만 ("틀린 걸 안 내보내는 게 어렵습니다")
- 로그인/OAuth — 시연에 안 씀
