# 주의사항 (사고 이력)

- `backend/.env`는 **UTF-8 필수** — PowerShell `>` 리다이렉트는 UTF-16으로 저장해 dotenv가 죽음. `Out-File -Encoding utf8` 사용
- `.env`는 절대 커밋 금지 (UPSTAGE_API_KEY·EXAONE_API_KEY 들어 있음)
- 푸시는 `feat/quiz-create`로
- 품질 판단은 폐기율이 아니라 **"저장분 중 실사용 가능 비율"** · 표본은 `--chunks 3 --budget 20` 이상으로
